# 🧠 DevBrain

An AI-powered developer assistant that understands entire codebases, answers questions about code, generates documentation, and helps developers understand projects faster.

---

## 🎯 Vision

DevBrain aims to become an intelligent engineering assistant capable of understanding any software project and helping developers navigate, learn, and contribute efficiently.

---

## 🚀 MVP Features

- User Authentication
- GitHub Repository Integration
- Repository File Parsing
- AI Chat with Codebase
- Documentation Generator
- Project Dashboard
